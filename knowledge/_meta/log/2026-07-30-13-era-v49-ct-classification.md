2026-07-30 — **Applied the control/treatment agroecological-gradient scoring to ERA v49 (crops) and produced a human-reviewable classification, driven by an exhaustive ontology-based practice crosswalk.** New script `ERA/Script/era_ct_classification.R`; outputs to Downloads (per golden rule 1).

Built `agroecology_practice_crosswalk_v1.csv` from the ontology sheet `01_practices` (342 subpractices): **every subpractice given a Gliessman level (L0–L3) and principle, or marked "not agroecology"** — 174 agroecological (L1 23, L2 73, L3 78), 168 not (L0 55, neutral 28, not-AE 85). The classifier joins each v49 practice value to this crosswalk (regex fallback only for ~4 values absent from the ontology). Deliverables: `ERA_ct_contrast_patterns_v49.csv` (distinct control→treatment bundle patterns), `ERA_ct_by_comparison_v49.csv`, `ERA_practice_levels_v49.csv`, `ERA_ct_classification_review_v49.html`, and my QA/QC review `ERA_ct_classification_QAQC_v49.md`. Counts (crops): 165,879 effect sizes / 4,983 distinct contrasts / 1,324 studies; buckets oriented 76,207 / no-AE-contrast 61,244 / unscoreable 27,140 / lateral 1,288; our control agrees with ERA's on ~88% of oriented contrasts and flips on 342.

Two findings worth acting on (both in the QA report, not fixed here): (1) **the ontology's own `agroecological principle` column is a coarse family tag that mislabels the conventional poles** — Monoculture, Bare Fallow and Simple Crop Rotation all carry the diversification principle, and Inorganic Fertilizer, synthetic pesticides and "No Chemical Applied" all carry `2_input_reduction`; it is also blank for 196/342. We did not use it directly (kept it as `ontology_principle_raw`); **suggest Lolita review/repair it at source** (we never edit the ontology, golden rule 2). (2) **`ERA_crop_data_short_v49.csv` contains ~201,000 embedded NUL bytes** that break a full `fread`/`read.csv`; the script strips them to a temp copy first — a v49 harmoniser output-quality issue to confirm. Also environmental: R 4.4.2 here segfaults intermittently (packages built under 4.4.3), so each R step is wrapped in a process-level retry loop.

Method documented in `control_treatment_scoring.md` (added the principle→practice table and the crosswalk realisation note) and in the standalone protocol (`Downloads/Agroecology_control_treatment_scoring_protocol_v01.{md,docx}`, new §5.4).
